## Objectives

- Understand the changed code at a high level in an easy way
- Identify code that doesn't align with the goals
- Investigate syntactic and semantic errors inside code
- Suggest structural improvements if any
- Provide other good suggestions if applicable

## Limits

- I'm reviewing this branch - I didn't write this code
- Excessive explanations are not necessary
- Use technical terms as-is without translation

## Checklist

- **Whether the changed code meets the objectives**
  - This is the most important
  - Does it meet the requirements
  - Are there any errors
  - Is the bug fix done properly
  - Does the new feature work correctly
- Are there any leftover debug code
- Are there any unnecessary comments
- Are variable names and function names appropriate
- Is the code complexity appropriate
  - Are there any violations of SOLID principles
  - Are there any files that are too long
- Are there any parts that could cause performance issues

## Code quality

- Unit tests and linting not performed (author's responsibility)
